# Техническое задание

## 1. Введение
Данное техническое задание описывает требования к разработке и запуску лендинг-сайта для онлайн-магазина уникального кофе «Hora Coffee». Сайт предназначен для презентации ассортимента, рассказа историй происхождения кофе и совершения покупок.

## 2. Информация о сайте

### 2.1. Назначение сайта

Основные цели:

* **Привлечение клиентов:** Люди из соцсетей(Instagram, TikTok, YouTube Shorts) будут посетителями сайта.

* **Презентация уникального торгового предложения:** Представление наборов для дегустации и «Клуба дегустаторов».

* **Стимулирование покупок:** Сделать так, чтобы люди могли легко оформить заказ и выгодно(Например: сделать его с какой-нибудь скидкой).

* **Формирование лояльности:** Сделать так, чтобы человек не просто купил кофе один раз, а захотел вернуться к нам снова и рассказать о нас друзьям.

### 2.2. Основные преимущества компании. 

* **Уникальность ассортимента:** Специализация на редких сортах кофе из разных регионов мира.

* **Образовательный подход:** У каждого сорта есть собственная карточка с историей, рассказом о фермере, регионе и методе заваривания в кратком виде.

* **Доступность:** Наш кофе может купить любой студент, для это необязательно быть богатым.

### 2.3. Целевая аудитория

* **Основная:** Студенты и офисные работники в возрасте 17-30 лет.

* **Наши покупатели:** Любознательные, ценящие новые впечатления, интересующиеся культурой и происхождением продуктов, ограниченные в бюджете, но готовые платить за качественный опыт.

* **Каналы привлечения:** Instagram (фото), TikTok/YouTube Shorts (короткие атмосферные видео).

## 3. Структура сайта

Лендинг будет представлять собой одностраничный сайт с навигацией по якорным ссылкам(ссылка, которая ведет не на другую страницу, а на определенный элемент на этой же странице).

**На всех страницах в верхней части расположены:**

* **Логотип «Hora Coffee»** 
* **Основное меню** (якорные ссылки):
    * Главная (о компании/преимущества)
    * О кофе (истории происхождения)
    * Наборы
    * Отзывы
    * Контакты
* **Кнопка «Корзина»** (товары и их общая сумма)
* **Основная информация о сайте**:
    * Hero section
    * Блок «Преимущества(section-benefits)
    * Блок «Наборы для дегустации» (Товары)
    * Блок «Истории происхождения» (О кофе)
    * Финальный блок CTА(Кнопка)


**В нижней части сайта расположены:**

* **Краткое повторение уникального торгового предложения**
* **Контакты:** email, ссылки на социальные сети (Instagram, TikTok, YouTube)
* **Информация:** Доставка по России, работа с поставщиком из Вьетнама
* **Копирайт**

## 4. Описание экранов (блоки лендинга)

### 4.1 (Hero Section)

**Цель:** Заинтересовать покупателя и за несколько секунд объяснить, что мы продаём и почему это круто.

**Элементы:**
* Красивое фото сверху: чашка ароматного кофе или зёрен.
* Заголовок H1: «Устали от одного и того же кофе?»
* Подзаголовок: «Откройте для себя 4 уникальных сорта с разных континентов. Скидка 20% на первый набор».
* Кнопка: «Начать путешествие» (ведет к блоку с товарами).
* Доп. кнопка: «Узнать истории» (ведет к блоку «О кофе»).

### 4.2. Блок «Преимущества / Как это работает»(section-benefits)

**Цель:** Ответить на вопросы, которые уже крутятся в голове у посетителя.

**Элементы (3-4 иконки с текстом):**
* «От фермера к вам»: Прямые поставки из Вьетнама и других регионов.
* «История в каждой чашке»: Открытка с фото и рассказом в каждом наборе.
* «Дешевле, чем по отдельности»: Экономия 20% на наборе.
* «Сюрприз каждый месяц»: Описание подписки «Кофе-сюрприз».

### 4.3. Блок «Наборы для дегустации» (Товары)

**Цель:** Презентация и продажа основного товара.

**Элементы:**
* Заголовок: «Набор «Путешествие по континентам».
* Карточка товара с изображением набора.
* Список континентов/регионов в наборе (Африка, Юж. Америка, Азия, ...).
* Цена: перечернутая старая цена и новая со скидкой 20%.
* Кнопка «Добавить в корзину».

### 4.4. Блок «Истории происхождения» (О кофе)

**Цель:** Сделать так, чтобы человек не просто купил кофе, а полюбил его историю.

**Элементы:** Слайдер с сортами из набора. Для каждого:
* Фото региона/фермера/зерен.
* Название сорта и региона.
* Краткий сторителлинг (2-3 предложения): высота, метод обработки, вкусовые ноты.

### 4.5. Финальный блок CTА(Кнопка)

**Цель:** Повторный призыв кдействиюю.

**Элементы:**
* Фоновое фото: счастливый клиент с чашкой на уютной кухне
* Заголовок: «Готовы к новым вкусам?»
* Краткое повторение предложения
* Кнопка: «Выбрать набор сейчас»

## 5. Требования к дизайну

* **Стиль:** Минималистичный, светлый. Акцент на больших фотографиях (зёрен, процесс, упаковка).
* **Цветовое решение:**
    * **Основной фон:** Светлый 
    * **Акцентные цвета:** Теплые, «кофейные» тона 
* **Графические материалы:** Будут подобраны из качественных стоков.

## 6. Технические требования

* **Технологии:** 
    * Front-end: HTML5, CSS3, JavaScript.
* **Адаптивность:** Адаптивный интерфейс для трех основных групп устройств:
    * **Десктоп:** 1920x1080, 1440x900, 1280x720
    * **Планшет:** 1024x768
    * **Мобильные:** 360x640, 375x667, 414x896. Принцип Mobile First

* **Браузеры:** Современные версии Chrome.
