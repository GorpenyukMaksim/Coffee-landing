# Обсуждение развития и улучшений сайта Hora Coffee

### Что можно улучшить

---

## 1. Блоки для улучшения

### 1.1. Главный экран (Hero)

| Текущая проблема | Предложение по улучшению | Приоритет |
|------------------|--------------------------|----------|
| Одна статичная картинка | Добавить **слайдер** с 3-4 кадрами: чашка кофе, упаковка на карте мира, счастливый клиент | Средний |
| Нет видео | Добавить **атмосферное видео** с процессом заваривания кофе (10-15 сек) | Низкий |
| Скидка не выделена динамически | Сделать **таймер обратного отсчета** до окончания акции | Средний |

### 1.2. Блок преимуществ

| Текущая проблема | Предложение по улучшению | Приоритет |
|------------------|--------------------------|----------|

### 1.3. Блок товаров (Набор)

| Текущая проблема | Предложение по улучшению | Приоритет |
|------------------|--------------------------|----------|
| Нет выбора размера упаковки | Добавить опции: **250г / 500г / 1кг** с пересчетом цены | Высокий |
| Один набор в каталоге | Добавить **2-3 дополнительных набора**: "Эспрессо-путешествие", "Для гурманов" | Средний |

### 1.4. Клуб дегустаторов

| Текущая проблема | Предложение по улучшению | Приоритет |
|------------------|--------------------------|----------|
| Нет примеров прошлых сортов | Добавить **галерею "Что было в прошлых месяцах"** с фотографиями и отзывами | Высокий |
| Нет вариантов подписки | Добавить выбор: **3 месяца / 6 месяцев / 12 месяцев** со скидкой за предоплату | Средний |
| Нет бесплатного пробного месяца | Добавить **пробный месяц за 50% стоимости** для привлечения новых участников | Высокий |
| Нет системы рефералов | Добавить **реферальную программу**: приведи друга — получи месяц бесплатно | Средний |
