# Hora Coffee — Лендинг онлайн-магазина кофе

## Описание проекта

Одностраничный сайт для продажи наборов кофе «Путешествие по континентам». Проект включает:

- 4 уникальных сорта кофе с разных континентов
- Истории фермеров и происхождения кофе
- Клуб дегустаторов с ежемесячной подпиской
- Корзина с сохранением данных в localStorage
- Адаптивный дизайн под все устройства
- Оптимизация скорости загрузки (lazy loading, defer, preconnect)

---

## Как запустить проект

### Способ 1: Простой (без сервера)

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в любом браузере (Chrome, Firefox, Safari)
3. Сайт готов к использованию
